# 운영 시연 실행기

구매자·판매자·관리자 창을 따로 띄우고, 장면에 맞는 창 하나만 화면 왼쪽 80%에 펼쳐요(나머지는 최소화). 오른쪽 20%에는 터미널을 두고 Enter로 장면을 넘겨요(`--auto`면 바로 이어서 실행).

짧게 실행하려면 `frontend` 폴더에서 `./demo/demo.sh`(뒤에 `--from 6` 같은 옵션을 그대로 붙여요). 화면 크기 기본값은 맥북 1728×1080이에요.

```bash
cd demo && npm install && npx playwright install chromium   # 처음 한 번
node run.mjs              # 새 시연 계정으로 처음부터
node run.mjs --from 6     # state.json 계정으로 6번 장면부터
node run.mjs --record     # videos/에 역할별 영상도 남김
node run.mjs --auto       # Enter 없이 이어서 실행, 실패하면 멈춤

# 맥북 Retina(논리 해상도 1728×1117)
DEMO_SCREEN_W=1728 DEMO_SCREEN_H=1080 node run.mjs
```

사람이 하는 일은 두 가지예요.

1. 시작할 때 관리자 창에서 로그인 (창을 닫으면 세션이 없어져요)
2. 5번 장면 끝에 구매자 창의 토스 결제창에서 테스트 결제

| 장면 | 창 | 내용 |
|---|---|---|
| 1 | 구매자 | 회원가입 → 로그인 (기본 배송지는 API로 저장) |
| 2 | 판매자 | 로그인 → 입점 신청 |
| 3 | 관리자 | 심사 시작 → 승인, 판매자 창이 권한을 받고 센터로 이동 (프로필은 API로 등록) |
| 4 | 판매자 | 상품 등록 (사진 `assets/product.png`) |
| 5 | 구매자 | 장바구니 담기 → 5만 원 충전 → **토스 결제창** |
| 6 | 구매자 | 주문 → 예치금 결제 |
| 7 | 판매자 | 송장 등록 (몇 초 뒤 배송 완료) |
| 8 | 구매자 | 구매확정 |
| 9 | 관리자 | 대기 건너뛰고 정산. 후보가 2건이 아니면 실행 전에 물어봐요 |
| 10 | 판매자 | 지갑 잔액 → 정산 상세 |

## 설정 (환경 변수)

| 이름 | 기본값 | 뜻 |
|---|---|---|
| `DEMO_SCREEN_W` / `DEMO_SCREEN_H` | 1920 / 1080 | 창을 나눌 화면 크기 |
| `DEMO_WIDTH_RATIO` | 0.8 | 창 폭 (화면 폭 대비) |
| `DEMO_SCALE` | 1 | 화면 배율. 1보다 작으면 더 넓게 보여요(창 폭 ÷ 배율 ≥ 1024면 데스크톱 레이아웃) |
| `DEMO_SLOWMO` | 120 | 동작 사이 지연(ms) |
| `DEMO_BEAT` | 1500 | 새 화면에 들어선 뒤 쉬는 시간(ms) |
| `DEMO_HOLD` | 3000 | 결과 화면(충전·주문 완료, 구매확정, 정산 등)을 보여 주는 시간(ms) |
| `DEMO_BASE_URL` | 운영 주소 | 다른 서버로 돌릴 때 |
