# 시안과 다르게 만든 곳

화면을 만들면서 시안(`design/screens/`)과 다르게 구현한 곳을 모아 둬요. 화면을 만들거나 고칠 때마다 이 파일에 이어서 적어요.
우선순위는 **실제 API > 팀 정책 > 시안**이고, 근거가 `design/DECISIONS.md`에 있으면 번호를 적어요.

**연결 전 표시 (2026-10-20)**: API가 없는 화면·섹션은 fixtures 대신 공통 `NotConnected`(‘아직 연결되지 않은 화면이에요’)로, 모르는 숫자는 `–`로, 서버를 부르지 못하는 버튼은 비활성 + ‘아직 연결되지 않은 기능이에요’로 보여요. 아래 표의 ‘fixtures’ 행은 실제 화면에서는 이렇게 보이고, fixtures는 `/__design` 미리보기에서만 써요.

| 화면 | 연결 전으로 보이는 것 |
|---|---|
| 홈 · 상품 목록 | 인기 농가 섹션 안내, 상품 카드의 관심(하트)·농가 카드의 팔로우 버튼 숨김 |
| 상품 상세 | 판매자 정보(생산 정보·농가 카드) 안내, 상점 링크 숨김, 관심·팔로우 버튼 비활성 |
| 농가 상점 `/farms/:id` | 화면 전체 |
| 마이 홈 | 프로필 영역 안내, 주문 현황·관심·팔로우 수·배송지 `–` (잔액·판매자 카드는 실제) |
| 관심 · 계정 관리 | 관심 두 탭 전체, 계정 관리 네 탭(내 정보·비밀번호·배송지·탈퇴) 각각 |
| 아이디·비밀번호 찾기 | 화면 전체 + 로그인으로 |
| 배송 조회 · 고객센터 문의 | 화면 전체 |
| 약관 보기(비회원) | ‘로그인하면 약관을 볼 수 있어요’ + 로그인 |
| 판매자 주문·출고 · 취소 요청 | 화면 전체 |
| 판매자 센터 홈 | 주문 집계 숫자 `–`, 처리할 일 안내 (정산 예정 금액은 실제 후보 합계) |
| 상점 프로필 | 팔로워 수 `–`, 팔로워 목록 안내 |
| 판매자 지갑 | 정산 계좌·출금 내역·입출금 내역 안내, 출금·계좌 변경 비활성 (잔액은 실제) |

**종류**
- `API 미완성`: API가 아직 없거나 작업 중이라 임시로 바꾼 것. **API가 나오면 시안대로 되돌릴 수 있어요** (코드에 `TODO(api)`)
- `API 계약`: 나온 API의 계약(필드·규칙)이 시안과 달라 API를 따른 것
- `정책`: 팀 정책·결정에 따른 것
- `접근성·UX`: 접근성 규칙이나 사용성 때문에 바꾼 것
