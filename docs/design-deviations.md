# 시안과 다르게 만든 곳

화면을 만들면서 시안(`design/screens/`)과 다르게 구현한 곳을 모아 둬요. 화면을 만들거나 고칠 때마다 이 파일에 이어서 적어요.
우선순위는 **실제 API > 팀 정책 > 시안**이고, 근거가 `design/DECISIONS.md`에 있으면 번호를 적어요.

**종류**
- `API 미완성`: API가 아직 없거나 작업 중이라 임시로 바꾼 것. **API가 나오면 시안대로 되돌릴 수 있어요** (코드에 `TODO(api)`)
- `API 계약`: 나온 API의 계약(필드·규칙)이 시안과 달라 API를 따른 것
- `정책`: 팀 정책·결정에 따른 것
- `접근성·UX`: 접근성 규칙이나 사용성 때문에 바꾼 것
